# MCP «Закупки» для OpenCode

MCP-сервер, который запускается на компьютере сотрудника и работает в OpenCode:

- **кто я**: логин Windows, ФИО и почта из Active Directory, вход не нужен;
- **заявки «В работе»** из общей Google-таблицы (лист «незакр 2025/26»: A — статус,
  S — ответственные «Руководитель/Сотрудник»);
- **ОКПД2**: поиск по приложенному классификатору (`data/okpd.xlsx`);
- **черновики ТЗ** по позициям;
- **ориентировочные цены** из интернета со ссылками на источник;
- **отчёт**: Google-таблица на Диске сотрудника (листы «В работе», «ТЗ», «Цены»),
  в папке «Отчёты MCP».

## Установка (сотрудник)

Запустите `Установить-MCP.bat`, полученный от администратора. Установщик:

1. ставит последнюю версию OpenCode (если её нет или она устарела);
2. скачивает этот MCP с GitHub и готовит Python через `uv`;
3. открывает браузер для входа в Google: нужен аккаунт с доступом к таблице заявок.
   На предупреждение «приложение не проверено» нажмите «Дополнительно → Перейти»;
4. спрашивает API-ключ LetAI и подключает модель LetAI-ONE;
5. вписывает MCP в конфиг OpenCode v1 или v2 (с резервной копией) и проверяет установку.

Чтобы обновиться, запустите тот же файл ещё раз. После установки перезапустите OpenCode
и напишите «кто я», затем «мои позиции в работе».

## Для администратора

1. Google Cloud: включить Google Sheets API и Google Drive API. Создать OAuth client
   **Desktop app** и перевести consent screen в **In production**.
2. Собрать установщик с ключом клиента. Ключ в GitHub не кладём: GitHub сообщает о таких
   ключах в Google, и клиент отключается.

   ```powershell
   .\tools\Make-Installer.ps1 -Repo <владелец>/<репозиторий> -GoogleClientPath C:\path\client_secret.json
   ```

3. Раздать получившийся `Установить-MCP.bat` сотрудникам внутри компании.

Доступы Google: `spreadsheets` (чтение таблицы заявок, создание отчётов) и `drive.file`
(только файлы, созданные приложением). Пока приложение не прошло проверку Google, Google
показывает предупреждение и пускает не больше 100 разных пользователей.

## Устройство

`server.py --stdio` — MCP для OpenCode (режим `GOOGLE_AUTH_MODE=local`).
`server.py --check` — самопроверка установки. Настройки задаются в `environment`
записи MCP в конфиге OpenCode: `REQUESTS_SPREADSHEET_ID`, `WORK_SHEET_NAME`,
`TOKEN_PATH`, `LOCAL_STATE_DIR`, `MCP_DRIVE_FOLDER`. Без `REQUESTS_SPREADSHEET_ID`
тот же `server.py` работает как HTTP-сервер по Excel-выгрузке (серверный режим).

Поиск цен идёт через HTML-версию DuckDuckGo и страницы магазинов. Это ориентир, а не
коммерческое предложение. При частых запросах поисковик временно ограничивает выдачу;
маркетплейсы (Ozon, WB, Avito) программам страницы не отдают.
